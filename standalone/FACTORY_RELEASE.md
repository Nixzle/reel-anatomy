## Actual capabilities

Start from an original saved Studio filming brief and source-linked claims. Create up to three editable opening variants, map statements to evidence, attach owned/licensed images or video, and attach authorised narration/audio or deliberately choose silent text cards. The renderer combines these into portrait video with on-screen text and captions. It uses source-video visuals without their audio; the chosen narration supplies the audio track.

Export a single variant or all three sequentially. Browser resolution options are 720 x 1280 and 1080 x 1920. It chooses an actually supported MP4 or WebM encoder and never just renames a container. Exportable supporting files include the original production JSON, SRT captions, source/provenance records, post caption and a prospective test card. The native tool renders MP4 using already installed Pillow and FFmpeg and reports actual dimensions, duration, hash and audio-track presence. No installer, paid generation or remote rendering service is activated.

Current reviewed, non-metadata evidence is required for factual assertions in human-reviewed mode. Changed/deleted sources, changed claims, script edits and media changes invalidate earlier review. Opposing evidence requires an explicit limitation in the spoken or on-screen material. Rights and clip/narration timing are checked. The four review attestations belong to a person reviewing the exact version; synthetic test attestations are not real human approval.

Draft export remains available and visibly marked when review is incomplete. Cancellation/backgrounding is not recorded as completion. Restoring campaign metadata clears prior approval and export receipts. Rendering and saving do not publish anything to a social account. These are production integrity checks, not independent fact verification or a virality score.

## Honest limits and ongoing scope

There is no guarantee of viral distribution and no calibrated view prediction. The script planner is structured; this release does not establish autonomous research depth or learned model quality. A citation can match text while the proposed interpretation is wrong. Human editorial judgment remains necessary.

Captions are distributed within the planned shot timings; they are not automatically aligned to the attached narration. Browser rendering runs in real time and must remain foregrounded. The current compositor assembles supplied footage, images, text and audio; it does not generate cinematic scenes, music or a cloned voice. Heavy original media remains bounded by existing device limits.

The existing outstanding requirements remain owned by Ultron Prime in the project handoff: physical iPhone/Safari and codecs, actual semantic/local-model inference and grounding, authorised social-account connectors, deeper full-text research, large real-media workloads, cross-device sync and measured campaign outcomes. The Sanctum public interface does not inherit this ChatGPT session's tools or private memory.

## Using this version

Collect evidence in Sanctum, save an original brief in Studio, then open Reel Factory. Select the brief and claims, create the variants, attach visuals/audio, save changes, inspect the preview and production checks, then export a draft or record a genuine review for the exact version. Use the test card and Results workflow to record real outcomes. Export is not automatic publication.

An installed copy may retain an earlier service-worker version until its old tabs are closed. Open the live page and fully close/reopen the app if the new tab is absent. Do not clear website storage merely to update; export important backups first. Backups exclude original media, narration and rendered videos, which should be saved separately.
