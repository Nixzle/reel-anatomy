LOCAL ANALYSIS SETTINGS

Know what
is doing the work.

English speech transcription and scene detection are included. Learned semantic analysis needs a separately installed local model.

Optional local model

No model downloads, API keys or paid cloud calls are made by this app. The connector uses only Ollama at 127.0.0.1:11434 and rejects declared cloud-backed models.

Semantic analysis has not been configured.

Choose a vision-capable model for sampled-frame descriptions. Text-only models analyse transcripts only. Model output is labelled as a suggestion. This is not a quality benchmark or a guarantee that a local service cannot be modified to forward data.

Data and scope

Source links are provenance, not an automatic downloader. Import footage you may process and genuine analytics. Keep creator, observation window and metric definitions consistent. Mobile filming briefs are exported files, not an exposed local server.

The app does not publish social posts, invent private insights or predict guaranteed virality.
